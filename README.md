# 📚 StudySnap AI

### Your AI-Powered Exam Study Assistant

> **Upload. Understand. Learn. Prepare. Score. 🚀**
> SEE THE FEATURE AND HOW IT'S WORK HERE :: https://ajai-studysnapai.streamlit.app/

StudySnap AI is an intelligent **AI-powered exam study assistant** designed to help students understand difficult academic content quickly and prepare effectively for examinations.

Using **Google Gemini Vision and Gemini Chat**, StudySnap AI can analyze question papers, textbook pages, handwritten notes, mathematical problems, circuit diagrams, programming questions, Data Structures and Algorithms problems, and other study materials.

Instead of spending hours trying to understand complicated study material, students can simply **upload an image or ask a question**, and StudySnap AI converts the content into a clear, structured, and easy-to-understand explanation.

---

## 🌟 Why StudySnap AI?

Students often face several problems while preparing for examinations:

- 📖 Difficult textbook explanations
- 📝 Confusing question papers
- ✍️ Hard-to-read handwritten notes
- 📐 Complex mathematical problems
- ⚡ Difficult electronic circuit diagrams
- 💻 Programming and coding problems
- 🌳 Data Structures and Algorithms concepts
- ⏰ Limited time before examinations
- 🤯 Difficulty converting concepts into exam-ready answers
- 🔄 Repeatedly searching multiple websites for explanations

StudySnap AI brings these tasks into **one intelligent study assistant**.

The student can upload a study image, ask a question, select the required answer format, and receive an AI-generated explanation tailored for examination preparation.

# 📝 3. Exam-Ready Answer Generation

One of the main features of StudySnap AI is its ability to generate answers based on the required **mark format**.

### ✏️ 2-Mark Answer

Provides:

- Short definition
- Important points
- Direct answer

### 📄 5-Mark Answer

Provides:

- Definition
- Explanation
- Important points
- Example when required

### 📚 8-Mark Answer

Provides:

- Introduction
- Definition
- Detailed explanation
- Working
- Steps
- Diagram explanation
- Example
- Applications
- Conclusion

### 📖 10-Mark Answer

Provides:

- Introduction
- Definition
- Concept
- Detailed explanation
- Working
- Diagram
- Example
- Advantages
- Applications
- Conclusion

### 📘 16-Mark Answer

Provides a detailed examination-oriented answer containing:

- Introduction
- Definition
- Detailed concept
- Architecture / block diagram
- Working principle
- Algorithm / procedure
- Example
- Advantages
- Disadvantages
- Applications
- Important exam points
- Conclusion

This allows students to generate answers according to the requirements of their examination.

# ⚙️ Installation

## 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/studysnap-ai.git
```

Move into the project directory:

```bash
cd studysnap-ai
```

---

## 2. Create a Virtual Environment

### Windows

```bash
python -m venv venv
```

Activate it:

```bash
venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv venv
```

```bash
source venv/bin/activate
```

---

# 📦 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

# 🔐 4. Configure Gemini API Key

Create:

```text
.streamlit/secrets.toml
```

Add:

```toml
GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
```

⚠️ **Never upload your API key to GitHub.**

Make sure `.streamlit/secrets.toml` is included in `.gitignore`.

---

# ▶️ 5. Run the Application

Start Streamlit:

```bash
streamlit run app.py
```

The application will open locally in your browser.

Usually:

```text
http://localhost:8501
```
